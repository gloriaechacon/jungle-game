GITHUB / PUBLICACION

Al revisar esta carpeta no existían .git ni un remoto configurado. No se ha
subido ni publicado nada. Falta el enlace del repositorio de GitHub y elegir
su visibilidad. Si aún no existe: crear un repositorio vacío en GitHub, elegir
público o privado y pasar su URL para conectar esta carpeta.

No usar git add . ni subir la carpeta entera sin revisar: hay documentos
personales, referencias y capturas que no hacen falta para jugar. node_modules,
artifacts y copias de Claude tampoco deben formar parte del despliegue.

Guardar código en GitHub no crea por sí solo el sitio. Para GitHub Pages con
Vite hace falta configurar el build/despliegue y la ruta base del repositorio
(incluida la imagen de consola y enlaces del juego). Eso sigue pendiente.
GitHub Pages con GitHub Free requiere repositorio público; desde un repositorio
privado exige un plan compatible o elegir otro hosting para la web pública.

Fuentes oficiales consultadas:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
https://vite.dev/guide/static-deploy.html#github-pages
