SOUNDTRACK DEL MAPA / PRIMERA NOTA — 03/10/2026

Petición vigente
Usar la pista de mapa suministrada por el usuario, conservando su carácter y
tono. Retirar el margen de grabación para que empiece en la primera nota.
Aplicar y registrar el mismo criterio para la intro y futuros audios.

Criterio de edición
«Primera nota» significa primera nota presente en el archivo recibido. Se
quita el silencio previo sin comerse su ataque; no se inventa un comienzo que
no haya quedado grabado. No se cambia melodía, velocidad ni afinación. Se
preserva el original completo y se crea una copia para el juego, con volumen
moderado. No se afirma separación de fuentes ni aprobación auditiva humana.

Integración
WorldMapScene y sus cartelas usan soundtrack/map; al volver de un nivel se
inicia desde cero. Intro usa soundtrack/intro. Niveles, bonus y celebración
NO se modificaron en este encargo. Pausa, pérdida de foco, silencio y ajustes
persistentes se conservan. Defaults 35% música / 65% efectos; no se borran
las preferencias existentes. El mapa conserva su atenuación adicional previa.
No se cambió jugabilidad, tutorial, guía de botones, sprites ni carcasa.

Regenerar
npm run audio:map -- --ffmpeg <ruta a ffmpeg.exe>
npm run audio:intro -- --ffmpeg <ruta a ffmpeg.exe>
FFmpeg solo se necesita para regenerar. El juego usa archivos incluidos,
sin depender de Zoom ni de carpetas de herramientas externas.
Los archivos .json junto a los audios registran cortes, ganancias y hashes.
